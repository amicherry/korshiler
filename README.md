# Көршілер (Соседи) — маркетинговая игра для E-KNOT

Пиксельная HTML5-игра: герой ходит по подъезду, стучится в двери и собирает подписи соседей за ОСИ.
Чистый JavaScript + Canvas 2D, без движков и без установки.

## Запуск
Открыть `index.html` в браузере (ПК, Android, iPhone).

## Как устроена игра (правки E-KNOT, 22.11)
1. **Пролог** — герой идёт домой через двор и подъезд, дома решает создать ОСИ.
2. **7 собраний**: инициативная группа → председатель и совет → тариф → летнее кафе → вышка оператора (2/3) → лифт → капремонт. Между ними — заставки «5 дней», «6 месяцев», «2 года».
3. **Квиз перед каждым собранием** (5 вопросов, со ссылкой на закон) пополняет бюджет дома; 80 %+ дают лишнее дожатие у Енота.
4. **Жильцы**: сценарии реплик от куратора (`src/scen_texts.js` — не править), новые типы: новосёлка, не-собственник, «мутный», подростки, арендатор. Статусы: за, против, воздержался, подумает, онлайн, бумага 📄, доверенность 🔑, не голосует.
5. **Енот E-KNOT** с собрания 2: уведомление → обзвон → дожатие → чат дома, с паузами в игровых днях.
6. **Протокол**: собрание 1 — бумажный № 1, дальше — «EKN-02…07, сформирован в E-KNOT» с долей онлайн-голосов.
7. **Озвучка**: игра сама ищет `out/kz/<id>.mp3` и `out/ru/<id>.mp3` по id из `voice/voice_lines.csv`; нет файла — обычный «писк» текста.

## Сборка
`python3 build.py` — склеивает файлы из `src/` в один `index.html`.

## Структура
- `src/engine.js` — экран, ввод, кнопки, звук, переходы
- `src/content.js` — интерфейс (kz/ru), типы жильцов, 7 туров, экономика в тенге
- `src/scen_texts.js` — реплики и сценарии от куратора (не править), `src/scen_glue.js` — подключение их к игре
- `src/interlude.js` — заставки между собраниями
- `src/voice.js`, `voice/` — озвучка по id
- `src/art_*.js` — процедурная пиксельная графика (персонажи, подъезд, ночной дом, портреты)
- `src/game.js` — сцены: меню, редактор героя, тур, итог
- `src/prologue.js` — пролог: герой сам идёт домой через двор и подъезд
- `src/house.js` — «Мой ЖК»: ремонты и список собраний
- `src/quiz.js`, `quiz/quiz_N_*.json` → `quiz.json` — квизы перед собраниями и «Знаток ЖКХ»
- `test*.js` — автотесты на Playwright
