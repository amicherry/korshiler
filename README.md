# Көршілер (Соседи) — маркетинговая игра для E-KNOT

Пиксельная HTML5-игра: герой ходит по подъезду, стучится в двери и собирает подписи соседей за ОСИ.
Чистый JavaScript + Canvas 2D, без движков и без установки.

## Запуск
Открыть `index.html` в браузере (ПК, Android, iPhone).

## Вход как житель
`index.html?token=demo` (или `#demo`) — тестовый житель ЖК «Нұрлы» (бонусы, рейтинг соседей). Без токена — гостевой режим.

## Сборка
`python3 build.py` — склеивает файлы из `src/` в один `index.html`.

## Структура
- `src/engine.js` — экран, ввод, кнопки, звук, переходы
- `src/content.js` — тексты (kz/ru), типы жильцов, туры
- `src/art_world.js` — люди и подъезд в разрезе
- `src/art_night.js` — ночной город для меню и двор у подъезда для пролога
- `src/art_portraits.js`, `src/art_head.js` — портреты для диалогов
- `src/api.js` — связь с сервером: заглушка `MockServer` (пока нет бэкенда) и клиент `API`; описание в `docs/API.md`
- `src/house.js` — «Мой ЖК»: карта дома, ремонты и украшения с анимацией установки, список собраний
- `src/game.js` — сцены: меню, редактор героя, пролог, тур, итог
- `test*.js` — автотесты на Playwright
