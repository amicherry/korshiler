# Көршілер (Соседи) — маркетинговая игра для E-KNOT

Пиксельная HTML5-игра: герой ходит по подъезду, стучится в двери и собирает подписи соседей за ОСИ.

**Играть онлайн:** https://claude.ai/artifact/68eg9GN7d6eP1VqyHiiMrb

## Как проверить (2–3 минуты)
1. Откройте https://amicherry.github.io/korshiler/ на телефоне (лучше горизонтально) или на компьютере.
2. Нажмите верхнюю кнопку меню (язык kz/ru меняется в «Настройках»), создайте героя (пол, причёска, одежда) — начнётся вступление у подъезда.
3. **Собрание 1:** управление — стрелки и кнопка действия (на компьютере ← → ↑ ↓ или WASD, действие — пробел/Enter), можно просто тапать по месту на экране.
   Подходите к дверям, стучите, выбирайте ответы жильцу. Цель — 6 подписей до конца таймера.
4. После победы нажмите **«Мой ЖК»**: купите ремонт подъездного света на заработанный бюджет — увидите анимацию установки.
5. Откроется собрание 2. Кнопка **«II»** — пауза и выход из уровня. Прогресс сохраняется.

С `?token=demo` в конце адреса игра входит как тестовый житель ЖК (рейтинг, бонусы). Сбросить прогресс: Настройки → Сбросить.
Требования к API для E-KNOT: [docs/API.md](docs/API.md).

## Как устроена игра
1. **Пролог** — вечер у подъезда, E-KNOT объясняет: без ОСИ ремонта не будет.
2. **Уровень = собрание** по очередной жалобе жильцов (свет, дверь, крыша, подвал, площадка, лифт, антенна, вывеска).
   Нужно обойти 9 этажей (по 6 квартир), уговорить соседей и собрать нужное число подписей за отведённое время.
   Часть соседей обещает подписать онлайн в E-KNOT — эти голоса приходят к концу собрания и показываются отдельно.
3. **«Мой ЖК»** — карта двора: на бюджет за собрание покупается ремонт, он ставится с анимацией и сохраняется.
   Следующее собрание открывается только после ремонта предыдущей проблемы; пройденные уровни можно переигрывать за деньги.
4. **Рейтинг «Лучший ЖК»**, ежедневный бонус в зависимости от состояния дома.

Сервер (пока заглушка) проверяет порядок уровней, деньги, подписи и слишком быстрые попытки — сжульничать нельзя.
Чистый JavaScript + Canvas 2D, без движков и без установки.

## Запуск
Открыть `index.html` в браузере (ПК, Android, iPhone).

## Вход как житель
`index.html?token=demo` (или `#demo`) — тестовый житель ЖК «Нұрлы» (бонусы, рейтинг соседей). Без токена — гостевой режим.

## Сборка
`python3 build.py` — склеивает файлы из `src/` в один `index.html`.

## Структура
- `src/engine.js` — экран, ввод, кнопки, звук, переходы
- `src/content.js` — тексты (kz/ru), типы жильцов, проблемы дома, уровни-собрания
- `src/art_world.js` — люди и подъезд в разрезе
- `src/art_night.js` — ночной город для меню и двор у подъезда для пролога
- `src/art_portraits.js`, `src/art_head.js` — портреты для диалогов
- `src/api.js` — связь с сервером: заглушка `MockServer` (пока нет бэкенда) и клиент `API`; описание в `docs/API.md`
- `src/house.js` — «Мой ЖК»: карта дома, ремонты и украшения с анимацией установки, список собраний
- `src/game.js` — сцены: меню, редактор героя, пролог, тур, итог
- `test*.js` — автотесты на Playwright: `test3` (весь проход), `test8`/`test14` (телефоны), `test10`/`test11` (сервер и офлайн),
  `test12` (тексты), `test18` (ремонты и уровни), `test19` (быстрый выход, подсчёт голосов)
