# Көршілер (Соседи) — маркетинговая игра для E-KNOT

Пиксельная HTML5-игра: герой ходит по подъезду, стучится в двери и собирает подписи соседей за ОСИ.
Чистый JavaScript + Canvas 2D, без движков и без установки.

## Запуск
Открыть `index.html` в браузере (ПК, Android, iPhone).

## Как устроено начало игры
1. **Пролог.** Герой идёт домой сам (стрелки/A-D или нажатие на экран). Во дворе сломан домофон, в подъезде пробегает крыса (герой подпрыгивает), с потолка капает в лужу (герой поскальзывается), лифт не работает — дальше пешком. На этажах соседи жалуются: Сара апа (свет), Ерлан (мусор), Бекет ата (крыша, подвал), на 6-м этаже Әсел с коляской — ей можно помочь. Дома герой решает создать ОСИ. Пролог можно пропустить кнопкой вверху.
2. **Собрание 1** — только обход дверей: приложения и енота ещё нет.
3. **Собрание 2.** Сосед Данияр рассказывает про E-KNOT: открываются онлайн-голоса и енот (рассылка). Каждая следующая рассылка слабее, повторно уведомлённые откликаются реже.
4. **Онлайн-голоса** приходят по ходу собрания, «за» и «против», — счётчик в верхней панели меняется. Часть соседей голосует в приложении сама.
5. **Отказы.** Часть соседей отказывает сразу на пороге (чаще ворчуны); после ремонтов отказников меньше.
6. **Бюджет.** Доплата сверх нормы — только за голоса, собранные у дверей, и не больше 10; рассылка енота денег не добавляет.

## Сборка
`python3 build.py` — склеивает файлы из `src/` в один `index.html`.

## Структура
- `src/engine.js` — экран, ввод, кнопки, звук, переходы
- `src/content.js` — тексты (kz/ru), типы жильцов, туры
- `src/art_*.js` — процедурная пиксельная графика (персонажи, подъезд, ночной дом, портреты)
- `src/game.js` — сцены: меню, редактор героя, тур, итог
- `src/prologue.js` — пролог: герой сам идёт домой через двор и подъезд
- `src/house.js` — «Мой ЖК»: ремонты и список собраний
- `src/quiz.js`, `quiz.json` — викторина «Знаток ЖКХ»
- `test*.js` — автотесты на Playwright
