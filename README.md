# Көршілер (Соседи) — маркетинговая игра для E-KNOT

Пиксельная HTML5-игра: герой ходит по подъезду, стучится в двери и собирает подписи соседей за ОСИ.

**Играть онлайн:** https://claude.ai/artifact/68eg9GN7d6eP1VqyHiiMrb

## Как проверить (2–3 минуты)
1. Откройте https://amicherry.github.io/korshiler/ на телефоне (лучше горизонтально) или на компьютере.
2. Нажмите верхнюю кнопку меню (язык kz/ru меняется в «Настройках»), создайте героя (пол, причёска, одежда) — начнётся вступление у подъезда.
3. **Собрание 1:** управление — стрелки и кнопка действия (на компьютере ← → ↑ ↓ или WASD, действие — пробел/Enter), можно просто тапать по месту на экране.
   Подходите к дверям, стучите, выбирайте ответы жильцу. Цель — 11 подписей (10 % от 104 квартир) до конца 60 игровых дней. Подъезд шире экрана — камера едет за героем.
4. После победы откроется собрание 2 «Выбор председателя»: нужна явка 53 квартиры и больше половины «за» (против тоже считается в явку).
5. Став председателем, в **«Мой ЖК»** почините свет без собрания — увидите анимацию установки. Кнопка **«II»** — пауза и выход из уровня. Прогресс сохраняется.

С `?token=demo` в конце адреса игра входит как тестовый житель ЖК (рейтинг, бонусы). Сбросить прогресс: Настройки → Сбросить.
Языки: казахский, русский, английский (Настройки или `?lang=en`). Запуск «как из приложения E-KNOT»:
`?token=test-123&lang=ru&name=Динара&level=4&tour=1&title=chairman&complex=ЖК%20Нұрлы` — см. docs/API.md.
Требования к API для E-KNOT: [docs/API.md](docs/API.md).

## Как устроена игра
1. **Пролог** — вечер у подъезда, E-KNOT объясняет: без ОСИ ремонта не будет.
2. **Туры = решения ОСИ по правилам голосования** (дом — 104 квартиры: 13 этажей × 8, 60 игровых дней на тур):
   инициативная группа (10 % «за» = 11), председатель и совет (явка 53, «за» больше половины), тариф (53 «за»),
   изменение конструкции — антенна и лифт (2/3 = 70 «за»). Обойти 104 двери нельзя — помогают E-KNOT:
   рассылка (онлайн-голоса, в том числе владельцев сдаваемых квартир), соседи, которые уговаривают друг друга,
   и совет дома, который после избрания сам обходит этажи.
3. **«Мой ЖК»** — карта двора: обычный ремонт (свет, дверь, крыша…) председатель делает сам за бюджет; антенну и лифт — только после собрания 2/3.
   Каждый ремонт повышает доверие соседей. Пройденные туры можно переигрывать за деньги.
4. **Викторина «Знаток ЖКХ»** — раннер в коридоре подъезда: крупный герой (тот же образ, что в игре) бежит,
   прыгает через преграды (касание экрана или Space), у трёх дверей — вопрос. Верная дверь — страница техпаспорта
   и монеты; неверная — объяснение, путь удлиняется, вопрос вернётся позже. В конце — дверь ОСИ и Бумажкин. 80 % верных с первой попытки — звание и значок «Знаток ЖКХ».
5. **Рейтинг «Лучший ЖК»**, ежедневный бонус в зависимости от состояния дома.

Сервер (пока заглушка) проверяет порядок уровней, деньги, подписи и слишком быстрые попытки — сжульничать нельзя.
Чистый JavaScript + Canvas 2D, без движков и без установки.

## Запуск
Открыть `index.html` в браузере (ПК, Android, iPhone).

## Вход как житель
`index.html?token=demo` (или `#demo`) — тестовый житель ЖК «Нұрлы» (бонусы, рейтинг соседей). Без токена — гостевой режим.

## Сборка
`python3 build.py` — склеивает файлы из `src/` в один `index.html`.

## Структура
- `src/engine.js` — экран, ввод, кнопки, звук, переходы
- `src/content.js` — тексты (kz/ru), типы жильцов, проблемы дома, уровни-собрания
- `src/art_world.js` — люди и подъезд в разрезе
- `src/art_night.js` — ночной город для меню и двор у подъезда для пролога
- `src/art_portraits.js`, `src/art_head.js` — портреты для диалогов
- `src/api.js` — связь с сервером: заглушка `MockServer` (пока нет бэкенда) и клиент `API`; описание в `docs/API.md`
- `src/house.js` — «Мой ЖК»: карта дома, ремонты и украшения с анимацией установки, список собраний
- `src/game.js` — сцены: меню, редактор героя, пролог, тур, итог
- `test*.js` — автотесты на Playwright: `test3` (весь проход), `test8`/`test14` (телефоны), `test10`/`test11` (сервер и офлайн),
  `test12` (тексты на kz/ru/en), `test18` (правила ОСИ, ремонты, туры), `test19` (быстрый выход, подсчёт голосов),
  `test21_launch` (запуск из приложения, результат через мост WebView), `test22_quiz` (бот проходит викторину), `test20_balance` (бот проходит туры: `NOISE=.4 WALK=1.5 node test20_balance.js` — «средний игрок»)

## Как менять вопросы викторины
Вопросы лежат в [`quiz.json`](quiz.json). Можно править прямо на GitHub (карандаш «Edit»), через 1–2 минуты игра на сайте подхватит новый файл — пересобирать не нужно.
```json
{ "id": "bulb",
  "q":       { "kz": "…", "ru": "Перегорела лампа в подъезде. Нужно ли общее собрание?", "en": "…" },
  "answers": [ { "ru": "Нет, председатель решает сам" }, { "ru": "Да, нужно 2/3 голосов" }, { "ru": "Да, нужен новый тариф" } ],
  "correct": 0,
  "explain": { "ru": "Обычный ремонт голосования не требует." } }
```
- `correct` — номер правильного ответа, считая с 0. Ответов — от 2 до 4 (столько же будет дверей).
- Вопросы и ответы перемешиваются при каждой игре, за раз показывается `questionsPerRun` вопросов.
- Если перевода нет, берётся `ru`. Битый вопрос (нет ответов, неверный `correct`) игра пропускает.
- Награды: `coinsFirstTry`, `coinsRetry`; доля верных с первой попытки для звания — `titleThreshold`.
- Чтобы встроенная копия в `index.html` тоже обновилась, запустите `python3 build.py`.
