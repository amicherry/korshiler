# Озвучка «Көршілер / Соседи» — задание для Әмины

## Что озвучить
- Все реплики — в `voice_lines.csv` (781 строка; колонки: id; герой; тур; ключ; эмоция; kz; ru).
- Каждая строка — два файла: казахский и русский.
- Имя файла = id: `out/kz/<id>.mp3` и `out/ru/<id>.mp3`. Игра ищет звук по id — не переименовывать.

## Порядок работы
1. Пробный заход: тур 1, Ворчун (grump) + Апа (apa) + реплики героя к ним — 23 строки × 2 языка. Отправить Виталию на проверку.
2. После согласования — остальные герои тура 1, затем туры 2–7.
3. Новые тексты не придумывать: только то, что в таблице. Правки текста — через Виталия.

## Эмоции (колонка «эмоция»)
- greet — нейтрально; good — заинтересованно; meh — сомневается; bad — раздражённо; yes — тепло, согласие; no — резкий отказ; think — задумчиво; abstain — уклончиво; story — жалоба; hold — настойчиво, перебивает; flee — тихо, быстро.
- Ремарок в тексте нет (зевок, вздох — отдельным звуком или тегом сервиса, не словами).

## Технические требования
- MP3, 44,1 кГц, моно, 128 кбит/с.
- Громкость выровнять (≈ −16 LUFS), без тишины в начале и в конце (≤ 0,2 с).
- Ударения и казахские буквы (ә, ө, ү, ұ, қ, ғ, ң, һ, і) — проверить на слух; если сервис читает неверно — сообщить Виталию.

## Сервисы (на выбор)
- ElevenLabs, модель eleven_v3 — казахский и русский одним голосом, эмоции тегами `[sighs]`, `[annoyed]`, есть API. Готовый скрипт: `tts_test.py` (вставить свой API-ключ и voice_id; ключ никому не пересылать).
- gptunnel (озвучка, у Виталия есть опыт) — проверить, есть ли казахский.
- Yandex SpeechKit (регион KZ) — хороший казахский (голоса Сауле, Жанар), но голосов мало — подходит для Енота и подсказок.
