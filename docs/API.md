# Көршілер — интеграция с приложением E-KNOT

Черновик требований к API от команды игры. Версия 1, 18.11.2026.

Игра — статическая HTML5-страница: https://amicherry.github.io/korshiler/
Своего сервера у игры нет. Прогресс, баллы и значки хранит приложение E-KNOT, а игра только сообщает результат.

## 1. Запуск игры из приложения

Приложение открывает страницу (внутри WebView или в браузере) и передаёт параметры в адресе:

```
https://amicherry.github.io/korshiler/?token=…&lang=kz&name=Әмина&level=3&tour=1&title=chairman&complex=ЖК%20Нұрлы
```

| Параметр | Обязательный | Пример | Что делает в игре |
|---|---|---|---|
| `token` | да* | `eyJhbGciOi…` | Одноразовый токен жителя. Игра возвращает его вместе с результатом. Без токена игра работает в гостевом режиме: играть можно, но результат никуда не отправляется. |
| `lang` | нет | `kz` / `ru` / `en` | Язык интерфейса. По умолчанию `kz`. |
| `name` | нет | `Әмина` | Имя героя и обращение в диалогах. |
| `level` | нет | `3` | Уровень пользователя в приложении. Показывается в меню и влияет на подсказки для новичков. |
| `tour` | нет | `1` | Последний пройденный тур (0–5, `-1` — ни одного). Игра открывает туры до `tour + 1`. |
| `title` | нет | `chairman` | Текущее звание, показывается в меню (список званий в разделе 4). |
| `complex` | нет | `ЖК Нұрлы` | Название ЖК на вывеске дома и в рейтинге. |

\* Без `token` включается гостевой режим.

**Важно для безопасности.** Параметры в адресе пользователь может изменить вручную. Поэтому `level`, `tour` и `title` для игры — только подсказка для отображения. Источник правды — ваш сервер: при начислении баллов проверяйте по своим данным, что тур действительно доступен этому пользователю.

## 2. Результат тура: что игра отправляет вам

Когда тур заканчивается (победа или поражение), игра формирует результат:

```json
{
  "version": 1,
  "game": "korshiler",
  "token": "eyJhbGciOi…",
  "runId": "r-1763457000-8f3a",
  "tour": 2,
  "tourCode": "tariff",
  "success": true,
  "rule": "half_plus_one_of_all",
  "apartments": 54,
  "votes": { "yes": 30, "no": 8, "undecided": 10, "notReached": 6, "turnout": 38 },
  "required": { "yes": 28, "turnout": null },
  "daysUsed": 41,
  "daysLimit": 60,
  "score": 1730,
  "firstWin": true,
  "badges": ["tariff_approved"],
  "startedAt": "2026-11-18T10:30:00Z",
  "finishedAt": "2026-11-18T10:38:12Z",
  "lang": "kz",
  "clientVersion": "1.4.0",
  "events": [ { "t": "yes", "apt": 5, "day": 3 }, … ]
}
```

- `runId` — уникальный номер попытки. Если связь оборвалась и игра отправила результат ещё раз, засчитывайте его один раз.
- `events` — журнал голосов по квартирам. По нему ваш сервер может сам пересчитать итог и не доверять числам из игры. Например, отклонять попытки, где 4+ голоса пришли быстрее чем за 15 секунд реального времени.
- `badges` — значки, которые игрок заработал в этой попытке. Баллы за них начисляет приложение.

### Способ доставки

Игра отправляет результат двумя путями, оба безопасно повторять:

1. **Сообщение в приложение** (если игра открыта в WebView), чтобы сразу показать значок или закрыть игру. Игра по очереди пробует:
   - `window.ReactNativeWebView.postMessage(json)` — React Native;
   - `window.webkit.messageHandlers.eknot.postMessage(json)` — iOS WKWebView;
   - `window.EKnot.postMessage(json)` — Android JavascriptInterface.
2. **Запрос на ваш сервер** — по нему начисляются баллы:
   ```
   POST {ваш адрес}/game/korshiler/result
   Authorization: Bearer <token>
   Content-Type: application/json

   <тело — JSON выше>
   ```
   Ожидаемый ответ:
   ```json
   { "ok": true, "pointsAdded": 50, "badgesAdded": ["tariff_approved"], "level": 4, "tour": 2, "title": "chairman" }
   ```
   Если пришло `ok: false` или сервер не ответил, игра показывает итог с пометкой «нет связи» и повторяет отправку при следующем запуске.

Адрес сервера задаётся в игре одной строкой (`API_CONFIG.baseUrl`). От вас нужен этот адрес и разрешение CORS для домена `amicherry.github.io`.

### Что нужно от вас

1. Адрес для `POST …/result` и формат токена (JWT или произвольная строка, срок жизни).
2. Как открывается игра: WebView (какой) или внешний браузер.
3. Подтвердить или поправить список туров и значков ниже.
4. Тестовый токен или тестовый стенд. Пока его нет, в игре работает заглушка: с `?token=demo` она изображает ваш сервер.

## 3. Туры и правила голосования

Дом в игре — 54 квартиры (9 этажей × 6). Время тура — 60 игровых дней. «Против» тоже считается в явку.
Порядок: тур открывается после победы в предыдущем; совет — после ремонта света, тариф — после трёх обычных ремонтов, замена лифта — после установки антенны.
Обычный ремонт открывается, когда игрок избран председателем (тур 1). В игре туры называются L1…L6 (`tour` = номер − 1).

| № | `tourCode` | Решение | Правило | Порог в игре |
|---|---|---|---|---|
| 0 | `initiative` | Инициативная группа | 10 % «за» от всех квартир | 6 «за» |
| 1 | `chairman` | Выбор председателя | участвуют 50 %+1 квартир, из них 50 %+1 «за» | явка 28, «за» 15 |
| 2 | `council` | Выбор совета дома | так же, как председатель | явка 28, «за» 15 |
| 3 | `tariff` | Утверждение тарифа | 50 %+1 «за» от всех квартир | 28 «за» |
| 4 | `construction` | Изменение конструкции (антенна на крышу) | 2/3 «за» от всех квартир | 36 «за» |
| 5 | `lift` | Изменение конструкции (замена лифта) | 2/3 «за» от всех квартир | 36 «за» |
| — | — | Обычный ремонт (лампы, кран, вывеска) | без голосования, решает председатель | — |

## 4. Значки и звания

| Значок | За что |
|---|---|
| `initiative_group` | Собрал инициативную группу |
| `chairman_elected` | Избран председателем |
| `council_elected` | Выбрал совет дома |
| `tariff_approved` | Утвердил тариф |
| `construction_approved` | Провёл решение 2/3 голосов (антенна) |
| `all_tours` | Прошёл все туры (замена лифта) |
| `zhkh_expert` | Звание «Знаток ЖКХ» за тур-викторину |

## 5. Как это работает сейчас

Пока вашего API нет, все запросы обслуживает заглушка `MockServer` в `src/api.js`. Она хранит данные в браузере и проверяет то же, что должен проверять настоящий сервер: порядок туров, уникальность квартир, слишком быстрые попытки и повторную отправку. Когда появится ваш адрес, достаточно указать его в `API_CONFIG.baseUrl`, остальная игра не меняется.

**Что уже есть и что в работе.** Уже работают: заглушка сервера с проверками, гостевой режим, повторная отправка, рейтинг. Туры по правилам ОСИ из раздела 3, игровые дни, явка и значки сделаны 18.11 (заглушка сервера проверяет те же правила). В работе: параметры запуска из раздела 1, английский язык, отправка результата в приложение.
