# Көршілер в Telegram (Mini App)

## Как подключить (один раз, делает владелец бота)
1. В Telegram открыть @BotFather → `/newbot` → придумать имя и username бота.
2. `/newapp` → выбрать бота → название «Көршілер», описание, картинка 640×360 →
   URL: `https://amicherry.github.io/korshiler/` → короткое имя, например `play`.
3. Ссылка на игру: `https://t.me/<username_бота>/play`. Можно добавить кнопку меню: `/setmenubutton` с тем же URL.

## Вход по номеру
- В Telegram игра сначала показывает экран «Войти по номеру» → `WebApp.requestContact()`.
  Без номера игра не открывается. Номер запоминается на устройстве, второй раз не спрашивается.
- На сервер (`POST /auth`) уходит `tg: { initData, contact, phone }`.
- **Сейчас сервер — заглушка и верит на слово.** Настоящий бэкенд должен:
  1. проверить подпись `initData` токеном бота (HMAC-SHA256, ключ = HMAC("WebAppData", bot_token)) и свежесть `auth_date`;
  2. проверить подпись строки `contact` тем же способом и что `contact.user_id` = `user.id` из initData;
  3. только после этого создать/найти пользователя по номеру.
  Токен бота хранится только на сервере, в игру и в репозиторий его не класть.
- Вне Telegram (обычный браузер) всё как раньше — гость или ссылка из приложения E-KNOT (`?token=`).

## Сообщения от бота (сертификаты, напоминания)
- Сразу после входа по номеру игра просит `WebApp.requestWriteAccess()` — «разрешить боту писать».
- Если игрок отказался — после каждой новой победы в доме появляется напоминание «Разрешить / Позже», а в Пауза → Настройки есть кнопка «Разрешить».
- Ответ уходит на сервер: `POST /tg/write { allowed }` (см. `docs/SERVER_API.md`, раздел 8). Бот пишет только тем, у кого `allowed: true`.
- Чтобы бот мог что-то прислать, на сервере должен работать сам бот (Bot API, токен бота) — это часть бэкенда E-KNOT.
